# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- **Primary Audience:** Technical recruiters, hiring managers, and engineering leads in cybersecurity and software engineering.
- **User Situation:** Evaluating candidates quickly for cybersecurity internships, entry-level security engineering, or full-stack roles.
- **User Goal:** Rapidly assess technical capability, project craftsmanship, security mindset, academic foundation (UANL FCFM), and practical credentials.

## Product Purpose

- **Purpose:** Serve as an interactive, highly engaging digital portfolio for Carlos Giovanni Reyes Medina.
- **Success Metric:** Clear conversion of visitors into contact inquiries, recruiter outreach, and interview invitations by leaving an unshakeable impression of technical discipline and security expertise.

## Positioning

- **Positioning Statement:** Cybersecurity student at UANL (Facultad de Ciencias Físico Matemáticas) who treats software and systems as evolving organisms—combining deep security awareness with modern web development skills.
- **Unique Angle:** Interactive terminal boot experience combined with sleek dark glassmorphism, showcasing both security domain knowledge and frontend proficiency.

## Operating Context

- Single-page responsive web application accessed on desktop and mobile browsers.
- Fast, visual evaluation flow featuring interactive sections: Hero / Presentation, Skills / Tools, Certifications, Projects, and Contact.

## Capabilities and Constraints

- **Confirmed Functionality:**
  - Interactive terminal boot sequence (`BootScreen.jsx`).
  - Animated backgrounds (`DigitalVoidBackground.jsx`, `DarkGlassBubbles.jsx`, `FlickeringGrid.jsx`).
  - Interactive presentation card with scramble text effects.
  - Categorized skill lists, project cards, certification showcases, and direct contact options.
- **Technical Stack:** React 19, Vite, TailwindCSS v4, GSAP, Animate.css.
- **Constraints:** Must load fast, maintain crisp responsive layout across all device viewports, and preserve accessibility alongside dark visual aesthetics.

## Brand Commitments

- **Owner:** Carlos Giovanni Reyes Medina
- **Institution:** Universidad Autónoma de Nuevo León (UANL) - Facultad de Ciencias Físico Matemáticas (FCFM).
- **Program:** Cybersecurity / Seguridad en Tecnologías de Información (3rd Year Student).
- **Tone & Identity:** Tactical, methodical, innovative, and security-focused. Dark cybersecurity aesthetic featuring terminal green/cyan highlights, subtle glassmorphism, and dynamic animations.

## Evidence on Hand

- **Repository Source:** `src/App.jsx`, `src/components/PresentationCard.jsx`, `src/components/BootScreen.jsx`, `src/components/Skills.jsx`, `src/components/Projects.jsx`, `src/components/Certifications.jsx`.
- **Identity & Philosophy:** Written self-introduction in `PresentationCard.jsx`.

## Product Principles

1. **Demonstrate Security Discipline:** Present technical depth and security-first thinking through design precision, code quality, and clear project context.
2. **Immediate & Lasting Visual Impact:** Engage visitors instantly with the terminal boot concept, while ensuring main content is readily accessible and effortless to navigate.
3. **Authentic Proof over Filler:** Highlight genuine academic progress, certifications, tools, and project work without fabricating metrics.
4. **Fluid & Immersive Experience:** Combine smooth animations (GSAP) and glassmorphic depth with high-performance responsive behavior.

## Accessibility & Inclusion

- Maintain legible text contrast against dark backgrounds.
- Provide smooth navigation and accessible keyboard controls/focus states.
- Ensure animations respect reduced motion preferences where applicable.
